JPG to PNG,
when a tool insists on it.

This one's worth being straight about: converting a JPG to PNG won't make it look better, and it'll make the file bigger. What it does buy you is a lossless format that picky tools accept and that you can edit without degrading. If that's what you need, it happens right here in the page, nothing uploaded.

The short version

Reach for PNG when something requires it — an editor, an upload form, a print or design pipeline that only takes PNG — or when you want a lossless working copy to edit and re-save without the picture losing a little each time. Those are real, good reasons.

What PNG won't do is improve the image. Your JPG already threw detail away when it was saved; PNG stores whatever's left exactly, artefacts and all, and can't recover what's gone. And because it's lossless, the PNG will be larger — for a photo, often much larger. You're paying bytes for compatibility and clean editing, not for quality.

The genuine reasons to do it

  • A tool that only accepts PNG. Some editors, avatar uploaders and design pipelines refuse JPG outright. PNG makes the file go through.
  • A lossless base for editing. If you'll open, edit and re-save the image several times, working in PNG stops each save from shaving quality — then export to JPG once at the end.
  • Before adding transparency. You can't make a JPG transparent, but a PNG copy is the right starting point to cut a background out in an editor.

The honest caveats

  • It won't look better. This is the one people get wrong most. A JPG's lost detail is lost; PNG preserves the current picture, artefacts included, and can't restore anything. Same look, bigger file.
  • The PNG will be larger. Lossless means no photographic compression, so a photo PNG can be several times the JPG's size. If you only need the image to open somewhere, keep the JPG — it's smaller and opens everywhere.
  • No transparency appears. A JPG has none to carry, so the PNG is fully opaque. Transparency has to be created in an editor; converting can't invent it.
  • Nothing uploads, and you can prove it. Watch the Network tab, or switch off your Wi-Fi and convert anyway. EXIF metadata is dropped in the re-encode; rotation is applied.

Questions people actually ask

Will JPG to PNG make my photo sharper?
No. The detail a JPG dropped is gone, and PNG can't bring it back. You get an identical-looking, larger copy — useful for compatibility and editing, not for quality.
Why did the file get bigger?
Because PNG is lossless and stores every pixel exactly, with none of JPG's photographic compression. For a photo that's a much heavier file for no visible gain.
Then why convert at all?
Because a specific tool needs PNG, or because you want a lossless copy to edit and re-save without degrading it. Outside those cases, the JPG is usually the better keep.
Does it add a transparent background?
No. A JPG has no transparency to carry, so the PNG is opaque. You'd cut the background out afterwards in an editor.
